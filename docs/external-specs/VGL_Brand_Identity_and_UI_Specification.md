# Vignesh GrowthLab (VGL) — ERP Brand Identity & UI Specification

This document defines the official brand identity, typography, corporate color palette, and visual specifications for the **Vignesh GrowthLab (VGL)** Enterprise Resource Planning systems.

---

## 1. Brand Identity Guidelines

* **Official Brand Name:** **Vignesh GrowthLab** (Short: **VGL**)
* **Tagline:** Enterprise Resource Planning & Intelligent Commerce
* **Acronym Badge:** **VGL**
* **Corporate Sequence Code:** `VGL/` (e.g., `VGL/26-27/001`)

---

## 2. Color Palette & Theming

| Role | Color Name | Hex Code | Purpose |
| :--- | :--- | :--- | :--- |
| **Primary Brand** | Growth Indigo | `#1e40af` | Primary buttons, active tabs, header gradients |
| **Primary Accent** | Electric Blue | `#3b82f6` | Hover states, interactive indicators |
| **Success / Tax** | Emerald Green | `#059669` | GST verified, payment receipts, positive yields |
| **Surface Dark** | Deep Navy Slate | `#0f172a` | Sidebar background, dark mode cards |
| **Surface Light** | Crisp Canvas | `#f8fafc` | Document backgrounds, table zebra striping |
| **Text Primary** | Charcoal Slate | `#334155` | High-contrast body typography |

---

## 3. UI Application Standards

### Frontend Application
* **Browser Page Title:** `<title>Vignesh GrowthLab (VGL) | Wholesale ERP</title>`
* **Header / Sidebar Badge:**
  * Displays **Vignesh GrowthLab** with the **VGL** brand monogram.
* **Login & Authentication Screen:**
  * Hero Title: **Vignesh GrowthLab Enterprise Portal**
  * Subtitle: Intelligent Wholesale, Inventory & Financial Accounting

### Corporate Database Configuration (`company_settings`)
All printable documents, delivery challans, tax invoices, and quotations must dynamically pull these official settings:
* **Company Legal Name:** Vignesh GrowthLab
* **Invoice Prefix:** `VGL-INV-`
* **Delivery Challan Prefix:** `VGL-DC-`
* **Purchase Order Prefix:** `VGL-PO-`
* **Quotation Prefix:** `VGL-QT-`
* **Footer Disclaimer:** *"Generated by Vignesh GrowthLab ERP. Authorized Signatory."*
